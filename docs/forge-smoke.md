# Three-Tier Application

This repository contains a reference implementation of a three-tier web application architecture. It features a Next.js frontend (React 19 with Tailwind CSS) communicating with an Express REST API, backed by a PostgreSQL database. The application is a simple task manager (to-do list) that demonstrates how the three tiers interact. It runs locally with Docker Compose for development and deploys to Google Cloud Platform using Terraform, with infrastructure provisioning for Cloud Run and Cloud SQL.
