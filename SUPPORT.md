# Support

## Getting Help

If you need help with this project or have questions, please open a GitHub issue:

1. Go to the [Issues page](../../issues)
2. Click on "New Issue"
3. Provide a clear title and description of your question or problem
4. Include any relevant details such as:
   - Steps to reproduce (if reporting a bug)
   - Expected vs actual behavior
   - Environment details (OS, Docker version, etc.)
   - Error messages or logs

We'll do our best to respond to your issue as soon as possible.

## Before Opening an Issue

Please check if your question has already been answered:
- Review existing [open issues](../../issues)
- Check [closed issues](../../issues?q=is%3Aissue+is%3Aclosed) for similar problems
- Read the [README.md](README.md) for setup and usage instructions

Thank you for using this project!
